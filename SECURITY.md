# Security Policy

## Supported Versions

We support security patches for the following versions of TravelMate AI:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it immediately to help keep the platform safe:

1. **Do not** disclose the vulnerability publicly in issues or pull requests.
2. Email your findings to `security@swecha.org` (or the project maintainers).
3. Include details, steps to reproduce, and any proof of concept scripts.

We will review your submission and work to resolve the issue as quickly as possible.
