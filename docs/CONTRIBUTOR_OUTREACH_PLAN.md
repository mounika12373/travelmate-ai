# Contributor Outreach Plan

This document outlines the week-wise plan to grow the contributor community for the open-source **TravelMate AI** project.

## Week-wise Contributor Onboarding Plan

### Week 1: Preparing the Repository Standards
* **Goal**: Establish a welcoming and clear developer workspace.
* **Activities**:
  - Update `CONTRIBUTING.md` with step-by-step setup guides using python virtual environment and `requirements.txt`.
  - Introduce pre-commit hooks (ruff, mypy, bandit) to make quality checks easy and uniform for new developers.
  - Tag initial beginner-friendly issues in GitLab with the `good first issue` label.

### Week 2: Internal Hackathons & Peer Recruitment
* **Goal**: Onboard close developer networks.
* **Activities**:
  - Present the architecture (`docs/ARCHITECTURE.md`) to campus coding clubs.
  - Encourage peers to contribute small features, such as adding a new city dataset or translating UI labels in `utils/i18n.py`.

### Week 3: Open-Source Forums & Community Outreach
* **Goal**: Reach external open-source contributors.
* **Activities**:
  - Post the repository on open-source directories and forums (e.g. Reddit r/opensource, Discord developer groups).
  - Invite UI/UX designers to propose cleaner dashboard layouts or custom CSS theme presets.

### Week 4: Contributor Recognition & Mentorship
* **Goal**: Retain active contributors.
* **Activities**:
  - Maintain a dedicated contributors section in the `README.md`.
  - Organize quick code review sessions to help contributors merge their merge requests (MRs) successfully.
