# Contributor Geographical Expansion Plan

This document outlines our strategy to expand the contributor footprint of **TravelMate AI** across various geographic regions.

## 1. Short-Term: Student Clubs in Regional Institutes (Weeks 1-4)
* **Goal**: Recuit developers from local colleges and universities.
* **Activities**:
  - Run hands-on workshops on Streamlit development, SQLite database querying, and GitLab CI/CD pipelines in neighboring engineering colleges.
  - Onboard student developers to maintain local city tourist lists.

## 2. Medium-Term: Statewide Tech Communities (Months 2-3)
* **Goal**: Expand outreach across regional open-source communities.
* **Activities**:
  - Engage with regional developer groups (e.g. Swecha local chapters, PyData user groups).
  - Seek regional language experts to contribute translations for Indic languages (Hindi, Telugu, Kannada, Tamil, Malayalam) in `utils/i18n.py`.

## 3. Long-Term: Global Open-Source Onboarding (Months 4-6)
* **Goal**: Establish a worldwide contributor base.
* **Activities**:
  - Promote the project at larger tech conferences and open-source events.
  - Standardize timezone-independent asynchronous developer communications (via GitLab issue boards and public chat servers) to allow contributors from all timezones to coordinate easily.
